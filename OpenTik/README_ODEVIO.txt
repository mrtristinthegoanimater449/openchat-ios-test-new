Open OpenTik on iPhone
============================

This is a Flutter iOS project generated by make_ios.py.

Web URL: https://exclude-certificates-semi-dollar.trycloudflare.com/opentik
Bundle ID: com.opentik.app

Sound is enabled in two places:
  * ios/Runner/AppDelegate.swift configures AVAudioSession (.playAndRecord)
    so media and notification sounds play even with the silent switch on.
  * ios/Runner/Info.plist declares the camera, microphone and photo-library
    usage strings and UIBackgroundModes=audio.

To build the IPA:
  1. Zip this whole folder (or use the zip next to it).
  2. Upload it to Odevio and choose the Ad-Hoc build type.
  3. Use the app identifier com.opentik.app that you created in Odevio/Apple.

Or from a terminal with Odevio installed:
  odevio build start --build-type ad-hoc "<APP_KEY>" .
  odevio build ipa
